# Kitchen AI gas ranges

These catalog products use Kitchen AI's parametric box-based WebGL geometry rather than a flat image or billboard. The model identity, real dimensions, finish, burner/griddle configuration and oven layout are stored on each editor object.

- `gas-range-32-4-burner`: 32 × 36 × 28 in, four burners, four controls, single oven.
- `gas-range-36-4-burner-griddle`: 36 × 36 × 28 in, four burners, center griddle with handle, dedicated fifth control, two oven doors.
- `gas-range-42-4-burner-griddle`: 42 × 36 × 28 in, four burners, center griddle with handle, dedicated fifth control, single extra-wide oven.

The default finish is `stainless-steel`. Body finish changes are independent from the stainless trim, cast-iron grates, brass burner details, griddle, oven glass and dark interior groups.
